# Layer catalogue preview images

Static JPEG screenshots captured from the live MapX maps in the local workspace
preview on 7 November 2026, at 910 × 624 pixels for early warning and fiscal resilience,
and 1148 × 782 pixels for earthquake losses. These are genuine map previews,
not generated illustrations or invented data. The images retain the rendered map
label, legend and provider attribution. The catalogue also identifies MapX and its
data providers beside the previews.

| File                  | Exact workspace variant             | MapX view              |
| --------------------- | ----------------------------------- | ---------------------- |
| `early-warning.jpg`   | `early-warning-coverage:0`          | `MX-SL3SM-AR11B-4LQ8T` |
| `fiscal-gap.jpg`      | `change-fiscal-gap:0`, with support | `MX-WOHMT-WYKWK-X25K9` |
| `earthquake-loss.jpg` | `aal-to-gdp-2025:0`, earthquake     | `MX-9NADN-CB8JT-WC1OD` |

To refresh, show that exact variant in **One layer** mode, wait for the map and its
matching legend to finish rendering, then capture the map region. Check each
image visually before replacing it. Keep the full image and its attribution;
the catalogue displays it without cropping. The live map remains the source of
current values. Other datasets use the searchable list until their own previews
are supplied; a generic map must not stand in for their data.

The images are served locally, so browsing the first-visit screen does not load
MapX or fetch live tiles. The map connection starts only when the Explore map step opens.
